# Evolução do Projeto


## 1. Primeira versão
Data: Agosto/2026

### Objetivo

Criar uma api para gerenciar uma coleção de cartas Pokémon no estilo pokedex e implementar um frontend simples para consumir a api.


### O que eu sabia antes de começar

- Como consumir apis externas;
- Como criar uma interface no front para consumir minha api;
- Não sabia o que era react;


### Backend

- Criei as camadas de api, domain, application e infra;
- Implementei uma pasta de external api;
- Criei controllers de importação para buscar as informações das apis externas;


### Frontend

- Criei as três paginas iniciais do meu projeto;
- Aprendi a consumir minha api através das services no front;
- Tive meu primeiro contato com React;
- Entendi melhor o conceito das rotas para navegar entre as paginas;
- Implementei pela primeira vez um responsividade simples;


### O que aprendi

- Entendi melhor o fluxo de uma aplicação, do front ate o banco passando pela api;
- Aprendi o básico de frontend;
- Aumentei meu conhecimento sobre apis e principalmente para que elas servem de verdade;


### Problemas que enfrentei

- Tive vários problemas com rotas e a forma que os endpoints são chamados;
- Sofri um pouco com a api externa de cards, já que era uma quantidade considerável de dados para importar e ela é uma api bem instável;
- Por ter pouco conhecimento com frontend eu precisei pesquisar muito para fazer esse projeto, mesmo ele sendo simples ate o momento;
- Demorei um pouco para entender o conceito de useState e useEffect no react, sendo algo que ainda esta meio vago para mim;


### O que eu ainda não sei

- Não considero que sei react ainda, é algo que tenho que me aprofundar bastante;
- Testes unitários, ambientes de desenvolvimento, ate mesmo rotas são coisas que eu tenho que estudar para poder utilizar;
- Como dar deploy no projeto, sei que é possível pela Vercel mas talvez não seja o ideal para o projeto;


### Próximos passos

Aplicar Autenticação no projeto, sendo que ainda é um conceito meio vago para mim.
